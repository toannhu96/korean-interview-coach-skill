## Update Rules

Update state after:

- kickoff completion
- company-prep completion
- each feedback cycle
- new story creation
- recurring weakness detected twice

Keep history compact:

- Preserve the most recent 10 practice rows.
- Summarize older rows into one bullet under recurring weaknesses or progress notes.
- Do not create complex migrations.

## Minimal Update After Feedback

If time is limited, update only:

- latest practice score row
- one recurring weakness if clear
- next recommended drill

## Story IDs

Use simple IDs:

- `S001`, `S002`, `S003`

Do not create more than one story from a single answer unless the candidate clearly provides separate situations.
